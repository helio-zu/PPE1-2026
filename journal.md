# Journal de bord du projet encadré
## Séance 2 - Travail fait
Nous avons classé des fichiers de types divers trouvés dans un dossier zip que nous avons téléchargé pendant le cours. Pendant cet exercice, j'ai appris à mieux maîtriser la commande mkdir, rmdir et mv. J'ai aussi pu mieux comprendre comment utiliser les jokers. A un moment, j'ai mal placé les fichiers .txt datant de 2016 et j'ai dû trouver un moyen de les remettre dans leur dossier parent avant de refaire le process du triage.

Ensuite, pour l'exercice *git-introduction*, j'ai pu utiliser git log pour voir les commits qui étaient enregistrés sur ma machine. Cela
 m'a permit de voir que le dernier mise-à-jour que j'ai effectué en ligne (l'ajout du journal de bord) n'a pas été répercuter du dépôt.
J'ai donc fait un git pull pour mettre à jour le dépôt sur ma machine et j'ai refait git log pour voir que que l'action a été bien fait du dépôt.

L'exercice *pipelines* a été particulièrement difficile car il m'a pris beaucoup de temps pour comprendre les commandes et leurs options ainsi que les instrucitons données. J'ai dû demander de l'aide à mes camarades. Néanmoins, j'ai pu m'en sortir.
